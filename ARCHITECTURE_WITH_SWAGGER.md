## ?? Request Flow with Swagger

### Example: Create Purchase Batch

```
1??  USER ACTION (Swagger UI)
    ?
    Click "POST /api/purchases"
    Fill in form:
    {
      "farmerId": "...",
      "productId": "...",
      "rawWeight": 1000.50,
      "ratePerKg": 50.00
    }
    Click "Execute"

2??  HTTP REQUEST
    ?
    POST https://localhost:7244/api/purchases
    Content-Type: application/json
    Body: { ... }

3??  API CONTROLLER (PurchasesController)
    ?
    [HttpPost]
    public async Task<ActionResult<ApiResponse<PurchaseBatch>>> 
        CreatePurchaseBatch([FromBody] CreatePurchaseBatchDto dto)
    
    - Receives DTO
    - Calls service
    - Handles exceptions
    - Returns ApiResponse<T>

4??  SERVICE LAYER (PurchaseService)
    ?
    public async Task<PurchaseBatch> 
        CreatePurchaseBatchAsync(CreatePurchaseBatchDto dto)
    
    - Validates input
    - Checks business rules
    - Calls DbContext
    - Returns entity

5??  DATA ACCESS (AppDbContext)
    ?
    _context.PurchaseBatches.Add(purchaseBatch);
    await _context.SaveChangesAsync();
    
    - Saves to database
    - Updates related tables
    - Returns saved entity

6??  DATABASE (PostgreSQL)
    ?
    INSERT INTO "PurchaseBatches" (...)
    VALUES (...)
    
    - Executes SQL
    - Applies constraints
    - Returns result

7??  RESPONSE TO SWAGGER
    ?
    {
      "success": true,
      "message": "Purchase batch created successfully",
      "data": {
        "purchaseBatchId": "a1b2c3d4-...",
        "totalAmount": 50025.00,
        "status": "Stored"
      }
    }
    
    Status: 201 Created
    Duration: 245 ms
```

## ?? Getting Started

1. **Run Application**
   ```bash
   dotnet run
   ```

2. **Open Swagger**
   ```
   https://localhost:7244/swagger
   ```

3. **Test an Endpoint**
   - Find "Master Data - Products"
   - Click "POST /api/products"
   - Click "Try it out"
   - Edit JSON and Execute

4. **View Results**
   - See response body
   - Check status code
   - View duration
   - Copy cURL command
